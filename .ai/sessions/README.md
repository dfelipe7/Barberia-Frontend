# .ai/sessions — Bitácora de sesiones con agentes de IA (Frontend)

Cada tarea completada con asistencia de un agente deja una entrada en este directorio:

    <YYYY-MM-DD>/<HHMM>-<slug>.md

Contenido mínimo (ver `AGENTS.md` §8):

- Herramienta, modelo y versión.
- Hash del commit resultante (o "sin commit").
- Prompt original del humano (texto literal).
- Plan ejecutado (resumen de componentes y lógica tocada).
- Suposiciones asumidas y riesgos.
- Resultado de `npm run build` y `npm run lint`.

**Este directorio se versiona**: es la fuente de verdad para auditoría de desarrollo asistido.
